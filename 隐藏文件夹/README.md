# 隐藏盘 HiddenDisk

一个 Windows 单文件小工具：给任意**数据盘**加一个「密码门禁 + 隐藏」的私人空间。
文件内容**不加密**，只是集中隐藏 + 密码门禁（软件层面的防翻找，不是保险箱）。

## 功能一览

- 双击运行 → 首次使用设置**本盘专属密码**（每个盘独立；5 次试错，错满锁 15 分钟，重启程序无法绕过）
- 验证通过 → 弹出一个新盘符（G、H、I… 自动挑空闲字母，绝不覆盖已有盘符）
- 把文件或文件夹**拖进程序窗口** → 原位置消失，集中存到本盘根目录的 `HiddenDiskVault`（隐藏 + 系统属性，资源管理器默认看不见）
- 程序运行中**再次双击 exe = 退出并卸下盘符**
- **多盘独立**：每个数据盘放一份 exe，各管各盘、各自密码、可同时运行、互不干扰

## 快速开始

1. 把 `HiddenDisk.exe` 复制到 **D、E 等数据盘**的任意文件夹（C 盘是系统盘，不创建任何数据；在 C 盘运行会直接弹提示）
2. 双击运行，按提示设置初始密码（至少 4 位）
3. 从资源管理器把要隐藏的文件/文件夹拖进程序窗口，状态栏会显示「已隐藏 N 个项目」
4. 点「打开盘符」查看已隐藏的内容；平时也可以直接在资源管理器访问这个新盘符
5. 用完点「关闭并退出」，或者再双击一次 exe —— 盘符卸下，一切恢复原样

## 使用规则

- **只管理所在数据盘**：D 盘的副本只能拖入 D 盘的文件；拖入其他盘的文件会被拒绝（请在对应盘上放一份 exe）
- **exe 随便挪**：数据文件夹固定在「盘根\HiddenDiskVault」，exe 在盘内任何位置运行看到的都是同一份数据
- **跨盘搬 exe**：它会开始管理目标盘自己的 HiddenDiskVault（那是独立的另一份数据）
- **忘记密码**：数据不会丢。删除 `%LOCALAPPDATA%\HiddenDisk\` 下对应盘的 `vault_*.cfg`（按修改时间辨认是哪个盘），下次运行重新设置密码即可
- **恢复文件**：打开盘符，把文件从盘符里拖出去（或剪切走）即可

## 安全说明

- 这是「隐藏 + 门禁」而非加密：别人若打开「显示隐藏文件」并知道 `HiddenDiskVault` 路径，理论上能绕过
- 首次映射盘符时，安全软件（如卡巴斯基）可能弹出拦截提示——选「允许」或将 `HiddenDisk.exe` 加入信任区即可
- 试错次数与锁定截止时间持久化在 `%LOCALAPPDATA%\HiddenDisk\`，重启程序、删除 exe 都不能绕过已生效的锁定

## 从源码构建

只需 Windows 自带的 .NET Framework 4.x `csc.exe`，无需安装任何 SDK：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

产物在 `bin\HiddenDisk.exe`。可运行 `bin\HiddenDisk.exe --selftest` 做无界面自检（密码哈希 / 锁定持久化 / 盘符选择 / 映射链路 / 移入规则）。

## 目录结构

```
├── HiddenDisk.exe    双击即用的成品
├── build.ps1         编译脚本（系统自带 csc.exe，C#5）
└── src/              源码（7 个文件）
    ├── Program.cs        入口：按数据文件夹区分的单实例、退出信号、--selftest
    ├── Config.cs         PBKDF2-SHA256 密码哈希、试错/锁定持久化（每盘独立配置）
    ├── DriveMapper.cs    盘符选择（现有最大盘符+1）、盘符映射/卸载/残留清理
    ├── VaultService.cs   盘根数据文件夹、移入/跨盘拒绝/重名处理
    ├── SetupForm.cs      首次运行设置密码
    ├── PasswordForm.cs   密码门禁（5 次 / 锁 15 分钟）
    └── VaultForm.cs      控制窗：打开盘符 / 关闭退出 / 拖入隐藏
```
