# 个人项目作品集

本仓库按项目分文件夹维护，每个文件夹内有各自的项目 README（功能、架构、快速开始）。

## 项目清单

- **[多智能体医疗电商项目](多智能体医疗电商项目/)** — 慢性病健康管理平台：AI 健康问答 + 药品商城 + Vue3 前端统一入口。Python 多智能体 RAG（LangGraph / Milvus / Ollama）负责健康问答与订单、资产查询，Spring Cloud Alibaba 微服务承载用户、积分、商城业务。
- **[隐藏文件夹](隐藏文件夹/)** — HiddenDisk 隐藏盘工具（C# / WinForms，单文件免安装 exe）：把数据盘里的数据文件夹映射成带密码保护的独立盘符，一键显示 / 隐藏，多盘互不干扰。
