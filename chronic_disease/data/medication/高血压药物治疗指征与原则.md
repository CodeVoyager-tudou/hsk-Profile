# 高血压药物治疗指征与治疗原则

来源：综合《中国高血压防治指南（2024年修订版）》《国家基层高血压防治管理指南（2017版）》中降压药物治疗的推荐整理。

## 血压多少需要开始吃降压药（启动药物治疗指征）

这是高血压患者最常问的问题，启动药物治疗取决于**血压水平**与**心血管风险分层**：

| 情况 | 处理建议 |
| --- | --- |
| 血压 140~159/90~99 mmHg，低危/中危 | 先生活方式干预（限盐、减重、运动、戒烟限酒）1~3 个月，血压仍 ≥140/90 mmHg 时启动药物治疗 |
| 血压 140~159/90~99 mmHg，高危/极高危（合并糖尿病、冠心病、肾病、已有靶器官损害等） | 生活方式干预同时，立即启动药物治疗 |
| 血压 ≥160/100 mmHg | 直接启动药物治疗，并同时进行生活方式干预 |
| 高危/极高危人群血压 130~139/85~89 mmHg | 可考虑启动药物治疗（是否用药由医生根据整体风险评估） |

**核心原则：高血压确诊后，多数患者需要长期药物治疗，不能只靠"感觉没症状"决定是否吃药。**

## 一般高血压患者的血压控制目标

- 一般高血压患者：目标血压 <140/90 mmHg；
- 能耐受且条件允许者（65~79 岁老年患者可先降至 <150/90，耐受良好再进一步）：可降至 <130/80 mmHg；
- 合并糖尿病、冠心病、慢性肾脏病者：多数指南建议 <130/80 mmHg；
- 老年患者（≥80 岁）：目标 <150/90 mmHg，如能耐受可进一步降低。

## 降压药物治疗的基本原则

1. **小剂量开始**：初始治疗采用较小有效剂量，缓慢平稳降压，避免血压降得过快过低；
2. **优选长效制剂**：优先使用每天一次、作用持续 24 小时以上的长效降压药，平稳控制 24 小时血压，提高服药依从性；
3. **联合治疗**：血压 ≥160/100 mmHg 或高于目标值 20/10 mmHg 者，可起始联合治疗；单药疗效不佳时优先联合用药；
4. **个体化用药**：根据患者年龄、合并疾病、耐受性和经济情况选择药物及剂量；
5. **终身服药观念**：高血压一般不能根治，多数需长期甚至终身规范服药，擅自停药会使血压反弹、心脑血管风险增加。

## 降压药物的联合用药方案

- 两药联合推荐：ACEI/ARB + 钙通道阻滞剂（CCB）、ACEI/ARB + 噻嗪类利尿剂、钙通道阻滞剂 + 噻嗪类利尿剂；
- 三药联合：在上述基础上加用第三种药物（如 ACEI/ARB + CCB + 利尿剂）；
- 单片固定复方制剂（复方降压片）可减少服药次数、改善依从性，是联合治疗的重要形式；
- 避免合用同类药物（如两种 ACEI 合用、两种 CCB 合用）以及 ACEI 与 ARB 联用。

## 各类降压药物的优势人群与常见不良反应

1. **钙通道阻滞剂（CCB，"地平"类）**：如氨氯地平、硝苯地平控释片。降压效果强，老年单纯收缩期高血压、合并冠心病/动脉粥样硬化者常用；常见不良反应：踝部水肿、面部潮红、头痛、心悸。
2. **血管紧张素转换酶抑制剂（ACEI，"普利"类）**：如依那普利、培哚普利。合并糖尿病、蛋白尿、心力衰竭者优选；常见不良反应：干咳、血钾升高、血管性水肿。
3. **血管紧张素Ⅱ受体阻滞剂（ARB，"沙坦"类）**：如缬沙坦、氯沙坦、厄贝沙坦。适应证同 ACEI，干咳发生率低；常见不良反应：血钾升高。
4. **噻嗪类利尿剂**：如氢氯噻嗪、吲达帕胺。老年高血压、单纯收缩期高血压、盐敏感性高血压常用；常见不良反应：低血钾、低血钠、血糖尿酸升高、血脂异常。
5. **β受体阻滞剂（"洛尔"类）**：如美托洛尔、比索洛尔。合并冠心病、心绞痛、心肌梗死、快速性心律失常者优选；常见不良反应：心动过缓、乏力、支气管痉挛；突然停药可致心绞痛加重（撤药反跳）。

## 用药期间的注意事项

1. 遵医嘱按时按量服药，每日固定时间（推荐晨起后），避免漏服；
2. 定期监测血压并记录，复诊时携带记录供医生调整用药；
3. 定期复查血钾、血肌酐、血脂、血糖、肝功能、心电图等（一般每 1~3 个月，稳定后可延长）；
4. 出现明显不良反应（如持续干咳、水肿、心率过慢等）及时就诊，由医生调整方案，不要自行换药停药；
5. 服用含"洛尔"类药物时不要突然停药，需在医生指导下逐渐减量；
6. 药物治疗必须与生活方式干预（限盐、减重、运动、戒烟限酒）同时进行，效果才最好。
